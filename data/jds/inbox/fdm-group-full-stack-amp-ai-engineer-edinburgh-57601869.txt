FDM is a global business and technology consultancy seeking a Full-Stack Engineer (PPM Tool Development) to work for our client within the Financial Services sector. This is initially a 6-12 month contract with the potential to extend and will be a hybrid role that will be based in Edinburgh. 

We're looking for a versatile engineer to take on development of a project and portfolio management (PPM) tool that's currently being built. You'll work across the full stack, from Node.js APIs and Postgres data models to agentic AI features and the Azure platform the tool runs on, then help move it to its target state in C# and React Native. 

Responsibilities 

- Pick up and extend the current Node.js solution, building and maintaining Fastify APIs and integrating them with the React front end.
- Integrate with Microsoft 365 data and services through the Microsoft Graph API.
- Design and manage the data layer using Postgres, SQL and Prisma schemas.
- Build agentic AI features with the right governance and controls, including deterministic workflows, agent skills and LLM integration.
- Build and maintain CI/CD pipelines in Azure DevOps, using Docker and Azure Pipelines.
- Run and secure the tool on Microsoft Azure, using AKS, Key Vault, Azure AI Foundry and Entra ID.
- Help develop the tool towards its target state in C# and React Native. About You 

- Full stack and backend development: strong Node.js experience, with Fastify APIs, the Microsoft Graph API and React front-end integration
- Data engineering: working knowledge of Postgres databases, SQL and Prisma schemas.
- Agentic and AI engineering: has delivered agentic solutions, including their governance and controls, deterministic approaches, agent skills and working with LLMs.
- CI/CD:Azure DevOps (ADO), Docker and Azure Pipelines.
- DevOps engineering: Microsoft Azure, including Key Vault, AKS, Azure AI Foundry and Entra ID.
- C# and React Native: full stack experience to support the tool's future development.
